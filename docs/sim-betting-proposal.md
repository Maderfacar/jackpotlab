# 線上模擬下注：需求問答與整體設計（暫緩）

> 2026-11-03 問答整理。**狀態：暫緩，設計尚未核准，還沒寫 spec、沒開工。** 回到此題時，從「整體設計待核准」這一步接著做。

## 使用者原始想法

- 會員專屬區塊，LINE 帳號登入；可管理的錢包；顯示名稱編輯；贏得獎金累積；頭銜系統。
- 基於 LIFF，針對 539、大樂透、威力彩、三星彩、四星彩、香港六合彩的線上**模擬**投注。
- 系統對會員發放投注金到錢包，派彩也派到錢包。
- 各彩種每期每種玩法都有即時賠率，依系統已投注金額動態調整。
- 各彩種玩法、賠率之後補。

## 我補的細節（待使用者核准）

- 只認官方開獎來源；第三方初步結果只顯示不結算。
- 後台可撤回重算：用反向帳目沖正，不刪原帳。
- 大單整張用「算進這張之後」的賠率；立柱／連碰拆成每組碰各自算風險、各自鎖賠率。
- 寫死不放後台：錢包記帳方式（流水帳算餘額）、每期流程順序、點數三條紅線。

## 整體設計（待核准）

1. **範圍與紅線**：jackpotlab 內、標示「非官方、純模擬」。
2. **會員**：LINE 登入，顯示名稱可改、頭像用 LINE；頭銜兩條線；排行榜週／月／總計；看不到別人注單；通知只在 App 內。
3. **錢包與莊家資金池**：每筆發放／扣款／派彩／撤回都是一筆帳；資金池起始預設 1 億點；扣款派彩只在伺服器做。
4. **每期流程**：開盤 → 收注（不撤單）→ 自動封盤 → 抓官方結果 → 自動結算派彩 → 可撤回重算。
5. **賠率：依風險調賠，國際盤四層上限**
   - 第一層 單筆上限（限押多少或限最多可贏多少）
   - 第二層 單一組合負債上限（預設資金池 1%），越接近賠率連續下滑，到上限封牌
   - 第三層 同一人累計上限（後台開關，預設開）
   - 第四層 整期總負債上限（預設資金池 5%）
6. **下注畫面**：點號碼、立柱／連碰；預留「帶入名單」接口。
7. **後台**：彩種玩法開關、封盤時間、賠率參數、各層上限、資金池、點數發放、頭銜與排行榜、開獎檢視與撤回重算、每期報表、會員查帳停權、設定修改紀錄。
8. **技術**：Nuxt 伺服器＋Firestore 交易，開獎抓取與結算接現有排程。（另案：錢包改關聯式資料庫，人多再評估。）

## 分期

1. 基礎：LINE 登入、會員區、錢包流水帳、點數發放、後台基本。
2. 539 下注：二三四星（70／800／12,500 倍，中獎另退本金）、立柱、連碰、依風險調賠、自動結算。
3. 其他彩種：等使用者補大樂透、威力彩、三星彩、四星彩、六合彩的玩法與起始賠率；接三星、四星、六合彩開獎資料。
4. 頭銜與排行榜。
5. 帶入名單：接重做的簡易版分析工具。
