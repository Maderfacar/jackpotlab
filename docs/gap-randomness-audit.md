# 隔期、值、位置的亂數檢定

由 `scripts/gap-randomness-audit.ts` 產生，任何人重跑都會得到一模一樣的數字。

## 資料與重跑

- 資料：`public/data/lotto539-history.json`，5997 期，96000001（2007-01-01）～ 115000253（2026-10-19）
- 檔案 SHA-256：`f73c946e074bbc439aeb4e097c576465274dc411ecca56d1238dc5cc9b729cb4`（檔案內容變了這串就會變）
- 重跑：`node --import tsx scripts/gap-randomness-audit.ts`（亂數種子 20261029、公平模擬 200 次，約 27 秒）
- 算法核對：腳本的容器算法跟頁面用的 `computeFeatures` 逐期比對隔期、值、x、y，**5997 / 5997 期一致**
- 前 60 期容器還沒裝滿，不算。

## 怎麼讀

- 「公平開獎」＝每期 39 取 5、跟過去完全無關。用同樣的開獎日跑 200 次，每次都用同一套容器算法算出同樣的項目。
- **p** ＝ 這些公平模擬裡，跟實際一樣偏、或更偏的比例。p 很小（< 0.01，粗體）＝ 公平開獎很難做出這麼偏的結果，代表那一項真的有規律。
- 右邊三欄是對照組：同樣的檢定拿去跑一段公平模擬、兩段故意埋了規律的模擬。埋了規律的那欄 p 變很小，代表這項檢定抓得到那種規律。
